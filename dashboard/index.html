Honesty note. The model is a ranking tool with honest error bars, not a price forecast: only ~30% of comparables are predicted within 2x, even by the best model tested. Validation is leave-one-out + bootstrap + random 5-fold CV. There is no time-split claim — the snapshot carries a single date, so a time split cannot be run honestly. Points programs are not inventoried: the snapshot carries no points data, so every row states that plainly. Stage discount (0.6x) and the concern haircut (0.10x) are disclosed priors, not fits.

Built from the sealed snapshot only. Method: log-log size curve fitted on traded comps, shrunk and damped category factors, growth and maturity factors, stage discount, band from LOO.
