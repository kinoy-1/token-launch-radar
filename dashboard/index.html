How the implied value is computed

Every row is scored by the same function, from the snapshot's figures alone. No protocol name is special-cased.

implied = TVL × 0.30 × growth × maturity × chains
  growth   = 1 + clamp(7d change, -50, +100) / 100 × 0.75
  maturity = 0.55 + 0.45 × min(age in days, 1095) / 1095
  chains   = 1 + 0.03 × min(extra chains, 5)

A token's fully diluted value usually tracks the value locked in its protocol, so TVL is the anchor. A protocol whose TVL is growing is winning users right now, so growth lifts the value — and the weight is deliberately strong (0.75) so the board is not a plain TVL table. A protocol that has run one to three years with no token has proved it can keep users without one, so age lifts it toward a full multiple. A protocol on several chains has more places to issue and more users to reach, so each extra chain adds a little. A protocol is ranked only when it records no token and is not a wrapped, staked or bridged product of a token that already trades: WBTC, Binance staked ETH and USDT0 are never ranked, because each is a product of a token that already trades.

Implied value is this entry's own claim, never a prediction that a token will be issued or when. Say a protocol records no token, never that it has none: a protocol on the board may still have a token its record does not carry.
